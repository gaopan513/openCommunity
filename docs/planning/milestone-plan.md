# 里程碑计划

## 项目总览

- 项目名称：openCommunity 社区论坛系统
- 技术栈：Django 5 + DRF + Vue 3 + Element Plus
- 复杂度：复杂项目（7 业务模块 + 1 公共模块）
- 开发模式：模块化顺序开发，逐模块审查

---

## 里程碑划分

### M1：项目骨架搭建（基础设施）

**目标**：完成项目初始化，前后端可联通。

**任务清单**：
1. 初始化 Django 项目（config + apps 目录结构）
2. 配置 DRF、SimpleJWT、CORS、django-filter
3. 配置数据库（开发环境 SQLite）
4. 初始化 Vue 3 + Vite 项目
5. 配置 Element Plus、Vue Router、Pinia、Axios
6. 实现 common 模块（权限类、分页器、异常处理、响应格式）
7. 前后端联通验证（健康检查接口）

**验收标准**：前端能成功调用后端 API 并展示响应。

---

### M2：用户认证模块（users）

**目标**：完成用户注册、登录、权限体系。

**任务清单**：
1. 实现 User 扩展模型（角色、头像、小区信息）
2. 实现注册接口（居民/商家/管理员）
3. 实现登录接口（JWT 签发）
4. 实现 Token 刷新接口
5. 实现个人资料 CRUD
6. 实现修改密码接口
7. 配置 Django Admin 用户管理
8. 前端：登录/注册页面
9. 前端：路由守卫 + Token 管理
10. 前端：个人中心页面
11. 单元测试（覆盖率 > 80%）

**验收标准**：用户可注册、登录、管理资料，权限控制生效。

---

### M3：自由发言模块（discussion）

**目标**：完成帖子发布、评论、互动功能。

**任务清单**：
1. 实现 Post、Comment、PostImage、PostLike 模型
2. 实现帖子 CRUD 接口（含图片上传）
3. 实现评论接口（支持楼中楼）
4. 实现点赞接口
5. 实现列表筛选（类型、标签、排序）
6. 实现管理员置顶/加精接口
7. 前端：帖子列表页（筛选、分页）
8. 前端：帖子详情页（评论、点赞）
9. 前端：发帖页面（图片上传）
10. 单元测试

**验收标准**：用户可发帖、评论、点赞，管理员可置顶/加精。

---

### M4：经验问答模块（qa）

**目标**：完成问答、采纳、互动功能。

**任务清单**：
1. 实现 Question、Answer、QuestionTag、QALike 模型
2. 实现问题 CRUD 接口
3. 实现回答接口
4. 实现采纳最佳答案接口
5. 实现点赞接口
6. 实现标签管理和筛选
7. 前端：问题列表页
8. 前端：问题详情页（回答、采纳）
9. 前端：提问页面
10. 单元测试

**验收标准**：用户可提问、回答、采纳，标签筛选正常。

---

### M5：二手市场模块（secondhand）

**目标**：完成商品发布、浏览、交易互动。

**任务清单**：
1. 实现 Product、ProductImage、ProductComment、ProductCategory 模型
2. 实现商品 CRUD 接口（含多图上传）
3. 实现商品状态流转接口
4. 实现留言接口
5. 实现分类筛选、价格排序
6. 初始化预设分类数据
7. 前端：商品列表页（分类、排序、搜索）
8. 前端：商品详情页（图片轮播、留言）
9. 前端：发布商品页面
10. 前端：我的商品管理
11. 单元测试

**验收标准**：用户可发布/管理商品，状态流转正确，留言正常。

---

### M6：商家板块（merchants）

**目标**：完成商家入驻、展示、活动、评价。

**任务清单**：
1. 实现 Merchant、MerchantImage、Activity、MerchantReview、MerchantCategory 模型
2. 实现商家入驻申请接口
3. 实现商家审核接口（管理员）
4. 实现商家列表/详情接口（分类筛选、搜索）
5. 实现商家信息编辑接口
6. 实现活动 CRUD 接口
7. 实现评价/评分接口 + 综合评分计算
8. 实现商家回复评价接口
9. 初始化商家分类数据
10. 前端：商家列表页（分类筛选）
11. 前端：商家详情页（信息+活动+评价）
12. 前端：商家入驻/管理页面
13. 前端：活动发布页面
14. 单元测试

**验收标准**：商家可入驻、管理店铺、发活动，居民可评价。

---

### M7：家政服务模块（housekeeping）

**目标**：完成服务展示、入驻、预约、评价。

**任务清单**：
1. 实现 ServiceProvider、ServiceCategory、ServiceItem、Booking、ServiceReview 模型
2. 实现服务商入驻申请接口
3. 实现服务分类/列表/详情接口
4. 实现在线预约接口
5. 实现预约状态流转接口（确认/拒绝/完成）
6. 实现服务评价接口
7. 实现预约记录查询（居民/服务商）
8. 初始化服务分类数据
9. 前端：服务分类/列表页
10. 前端：服务详情页
11. 前端：预约页面
12. 前端：我的预约/服务管理
13. 单元测试

**验收标准**：居民可预约服务，服务商可管理预约，评价正常。

---

### M8：系统管理 + 集成（admin_system）

**目标**：完成管理功能，全系统集成联调。

**任务清单**：
1. 实现 Announcement 模型和公告 CRUD 接口
2. 实现 Report 举报模型和接口
3. 实现基础数据统计接口
4. 增强 Django Admin 配置（所有模块）
5. 前端：管理后台页面（公告、举报、统计）
6. 前端：首页整合（公告展示、各板块入口）
7. 全系统集成测试
8. 端到端流程验证
9. 性能/安全检查

**验收标准**：管理功能完整，全流程跑通，无集成问题。

---

## 里程碑依赖关系

```
M1（骨架）→ M2（用户）→ M3（发言）→ M4（问答）
                                    → M5（二手）
                                    → M6（商家）
                                    → M7（家政）
                                         ↓
                                    M8（管理+集成）
```

M3-M7 之间无强依赖，理论上可并行，但建议顺序执行以保证代码风格一致。

---

## 质量检查点

| 检查点 | 时机 | 内容 |
|--------|------|------|
| 即时审查 | 每个函数完成后 | 语法、注释、职责单一 |
| 模块审查 | 每个里程碑完成时 | 测试覆盖、接口完整、代码规范 |
| 集成审查 | M8 完成后 | 端到端测试、性能、安全、文档 |
| 用户确认 | 每个模块完成后 | 展示成果、确认无误后继续 |
