# 发布说明 — openCommunity v1.0.0 MVP

## 发布日期
2026-07-27

## 概述
openCommunity 社区论坛系统 MVP 版本，以小区为中心，整合商家、二手交易、问答、家政服务等社区生活场景。

## 技术栈
- 后端：Python 3.13 + Django 6.0 + Django REST Framework
- 前端：Vue 3 + Vite + Element Plus + Pinia
- 认证：JWT (SimpleJWT)
- 数据库：SQLite（开发）/ PostgreSQL（生产）

## 已实现功能

### 用户体系
- 注册/登录（JWT Token 认证）
- 四种角色：游客、居民、商家、管理员
- 个人资料管理、密码修改
- RBAC 权限控制

### 自由发言
- 帖子发布（支持图片、标签、分类）
- 评论（支持楼中楼回复）
- 点赞
- 管理员置顶/加精

### 经验问答
- 提问（支持标签分类）
- 回答
- 采纳最佳答案
- 点赞（问题/回答）

### 二手市场
- 商品发布（多图、分类、成色）
- 分类筛选、价格排序
- 商品状态流转（在售→已预订→已售出/已下架）
- 买家留言

### 商家板块
- 商家入驻申请 + 管理员审核
- 店铺信息展示（分类筛选、搜索）
- 活动发布
- 评价/评分 + 商家回复

### 家政服务
- 服务分类展示
- 服务商入驻 + 审核
- 在线预约 + 状态流转
- 服务评价

### 系统管理
- 公告管理
- 内容举报 + 处理
- 基础数据统计
- Django Admin 全模块后台

## 测试覆盖
- 总计 137 个单元测试，全部通过
- 覆盖所有 API 端点的正常流程、权限控制、边界条件

## 已知限制（后续迭代）
- 前端业务页面为占位组件，需逐步实现完整交互
- 私信功能未实现（MVP 简化为留言）
- 图片存储为本地 Media 目录（后续迁移 OSS）
- 短信验证码为模拟实现
- 无 WebSocket 实时通知
