# 社区论坛系统 — 产品需求文档（PRD）

## 项目概述

### 项目名称
openCommunity — 以小区为中心的社区论坛系统

### 项目背景
为城市住宅小区打造一个线上社区交流平台，整合周边商家资源、二手交易、生活问答、家政服务等高频生活场景，促进邻里互动和社区商业生态。

### 项目目标
- MVP 阶段：跑通核心业务流程，验证产品可行性
- 后续规划：功能完善后迁移至微信小程序，扩大用户触达

### 目标用户
- 小区居民（核心用户）
- 小区周边商家
- 家政服务提供商
- 物业/社区管理员

---

## 用户角色与权限

### 游客（未登录）
- 浏览所有板块的公开内容
- 查看商家信息、二手商品列表
- 不可发帖、评论、预约

### 普通居民用户
- 注册/登录（手机号 + 验证码 或 用户名密码）
- 自由发言板块：发帖、评论、点赞
- 经验问答板块：提问、回答、采纳最佳答案
- 二手市场：发布/管理自己的商品、留言、私信
- 商家板块：浏览商家、参与活动、评价打分
- 家政服务：浏览服务、在线预约、评价
- 个人中心：管理自己的发布、收藏、消息

### 商家用户
- 入驻申请（提交营业执照、店铺信息）
- 管理店铺信息（名称、地址、电话、营业时间、图片）
- 发布/管理活动（促销、打折、团购）
- 查看和回复居民评价
- 商家后台：查看店铺数据概览

### 管理员/物业
- 用户管理（审核、禁用、角色分配）
- 商家入驻审核
- 内容审核（帖子、评论、商品）
- 板块管理（创建/编辑/排序板块）
- 家政服务分类管理
- 系统公告发布
- 数据统计概览

## 功能模块详述

### 模块一：用户与认证（user_auth）

**注册与登录**
- 支持用户名 + 密码注册
- 支持手机号 + 短信验证码登录（MVP 可先模拟）
- JWT Token 认证机制
- 角色区分：居民、商家、管理员

**个人中心**
- 修改个人资料（头像、昵称、小区信息）
- 我的发布（帖子、商品、问答）
- 我的收藏
- 消息通知（系统通知、评论提醒、私信）

### 模块二：商家板块（merchant）

**商家入驻**
- 商家提交入驻申请：店铺名称、分类、地址、联系电话、营业时间、营业执照图片、店铺照片
- 管理员审核通过后上线

**店铺展示**
- 商家列表页：支持按分类筛选（餐饮、超市、美容美发、教育培训、医疗健康等）
- 商家详情页：完整信息展示 + 地图位置 + 活动列表 + 评价列表
- 支持搜索（按名称、分类）

**活动发布**
- 商家发布活动：标题、描述、图片、活动时间、优惠内容
- 活动列表展示（进行中/已结束）
- 居民可浏览活动详情

**评价系统**
- 居民对商家进行评分（1-5 星）+ 文字评价
- 商家可回复评价
- 商家综合评分自动计算

### 模块三：二手市场（second_hand）

**商品发布**
- 发布闲置：标题、描述、图片（最多 9 张）、价格、分类、成色
- 分类：家具家电、数码电子、服装鞋帽、图书文具、母婴用品、运动户外、其他

**商品浏览**
- 商品列表：支持分类筛选、价格排序、最新发布排序
- 商品详情：图片轮播、描述、卖家信息、留言区
- 搜索功能

**交易互动**
- 留言：买家在商品下留言，卖家回复
- 私信：买家可私信卖家（MVP 阶段简化为站内消息）
- 状态管理：在售 → 已预订 → 已售出 / 已下架

**商品管理**
- 卖家可编辑、下架、删除自己的商品
- 标记已售出

### 模块四：经验问答（qa）

**提问**
- 发布问题：标题、详细描述、标签（装修、育儿、养宠、法律、医疗等）
- 问题列表：最新、热门、待回答筛选

**回答**
- 居民回答问题
- 提问者采纳最佳答案
- 回答支持点赞排序

**互动**
- 问题/回答点赞
- 评论补充

### 模块五：自由发言（discussion）

**发帖**
- 发布帖子：标题、内容、图片（最多 9 张）、话题标签
- 帖子类型：闲聊、求助、分享、公告（管理员）

**浏览与互动**
- 帖子列表：最新、热门、精华
- 帖子详情 + 评论区（支持楼中楼回复）
- 点赞、收藏
- 管理员可置顶、加精、删除

### 模块六：家政服务（housekeeping）

**服务展示**
- 服务分类：保洁清洗、家电维修、管道疏通、搬家服务、月嫂育儿、老人护理、其他
- 服务列表：按分类浏览、按评分/价格排序
- 服务详情：服务内容、价格、服务商信息、评价

**服务商入驻**
- 提交入驻申请：服务类型、服务区域、价格范围、资质证明、联系方式
- 管理员审核

**在线预约**
- 居民选择服务 → 选择时间 → 提交预约
- 预约状态：待确认 → 已确认 → 服务中 → 已完成 → 已评价
- 服务商确认/拒绝预约

**服务评价**
- 服务完成后居民评价（评分 + 文字）
- 评价展示在服务详情页

### 模块七：系统管理（admin_system）

**内容审核**
- 帖子/评论/商品举报处理
- 敏感词过滤（MVP 可简化）

**用户管理**
- 用户列表、搜索、禁用/启用
- 角色分配

**板块管理**
- 板块/分类的增删改查
- 排序管理

**公告管理**
- 发布/编辑/删除系统公告
- 公告在首页展示

**数据统计（MVP 简化）**
- 用户数、帖子数、商家数等基础统计

## 非功能需求

### 性能（MVP 标准）
- 页面加载时间 < 3 秒
- API 响应时间 < 500ms
- 支持 100 并发用户

### 安全
- 密码加密存储（bcrypt）
- JWT Token 过期与刷新机制
- 接口权限校验（RBAC）
- 图片上传类型和大小限制
- SQL 注入/XSS 防护（Django 内置）

### 可用性
- 响应式设计，适配 PC 和移动端浏览器
- 清晰的错误提示
- 操作反馈（加载状态、成功/失败提示）

---

## 技术约束

- 后端：Python + Django + Django REST Framework
- 前端：MVP 阶段使用 Django 模板 + Bootstrap（或 Vue.js SPA，待阶段 3 确认）
- 数据库：PostgreSQL（或 SQLite 用于开发）
- 文件存储：本地存储（MVP），后续可迁移至 OSS
- 部署：开发环境本地运行，后续考虑 Docker 容器化

---

## MVP 范围界定

### MVP 包含（P0）
- 用户注册/登录/角色区分
- 商家入驻、展示、活动发布、评价
- 二手市场发布/浏览/留言/状态管理
- 经验问答提问/回答/采纳
- 自由发言发帖/评论/点赞
- 家政服务展示/预约/评价/入驻
- 基础后台管理（用户/内容/分类管理）

### MVP 不包含（后续迭代）
- 微信小程序
- 实时聊天（WebSocket 私信）
- 在线支付
- 地图 API 集成
- 短信验证码（MVP 用模拟）
- 高级搜索/推荐算法
- 数据大屏/高级统计
