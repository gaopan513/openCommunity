# 功能清单（Feature List）

> 优先级说明：P0 = MVP 必须实现 | P1 = 重要但可延后 | P2 = 锦上添花

---

## 一、用户与认证（user_auth）

| 编号 | 功能点 | 优先级 | 说明 |
|------|--------|--------|------|
| AUTH-01 | 用户注册（用户名+密码） | P0 | 支持居民和商家两种注册入口 |
| AUTH-02 | 用户登录（JWT） | P0 | 返回 access + refresh token |
| AUTH-03 | Token 刷新 | P0 | 无感续期 |
| AUTH-04 | 角色权限控制（RBAC） | P0 | 居民/商家/管理员/游客四级权限 |
| AUTH-05 | 个人资料管理 | P0 | 头像、昵称、小区、联系方式 |
| AUTH-06 | 修改密码 | P0 | 验证旧密码后修改 |
| AUTH-07 | 手机号+验证码登录 | P1 | MVP 阶段模拟验证码 |
| AUTH-08 | 消息通知中心 | P1 | 系统通知、评论提醒 |
| AUTH-09 | 我的收藏 | P1 | 收藏帖子、商品、商家 |
